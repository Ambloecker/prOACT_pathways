# prOACT_pathways

This repository contains all R code, data, and figures that were used in the paper. 

The folders contain the following files:

- Data folder: PrOACT consequence table showing alternatives per objectives as filled in by stakeholders.
- R_code: the R code to perform the scoring analyses on how the alternatives achieve the objectives.
- Figures: includes all figures that are included in the paper.
